# 基于 RAG 的轻量级企业工艺生成系统

> 中国科学技术大学软件学院 · 研究生软件工程实践（工程实践）项目
>
> 基于检索增强生成（RAG）的企业级机械加工工艺生成系统：自动解析工艺文档，通过混合检索与重排序精准召回工艺知识，生成带引用溯源的零件加工指令。

## 一、项目简介

本项目利用开源向量数据库与开源大模型 API，构建一个**企业级工艺生成系统**。系统支持工艺文档（PDF）的自动解析、分块、向量化存储，实现检索增强生成（RAG），最终输出零件的加工指令。

核心目标是达到**企业级的准确度与有效性**：生成的参数真实可用、可核对、可追溯，而不是仅供演示的玩具 Demo。

## 二、核心功能（对应任务要求）

1. **文档格式解析**：解析工艺 PDF 的文字、表格、页码与版面结构；
2. **稠密 + 稀疏混合召回**：BGE 稠密向量检索 + BM25 关键词检索，RRF 融合；
3. **重排序模块**：Cross-encoder（bge-reranker）对候选结果二次精排，提升精度；
4. **多轮对话与引用溯源**：支持上下文追问，生成结果标注来源、可定位到原文页码；
5. **多文档准确率测试**：在多份文档上通过人工评估验证检索与生成质量。

## 三、技术栈

| 模块 | 技术选型 |
|---|---|
| 语言 | Python 3.10+ |
| RAG 框架 | LangChain |
| 向量数据库 | Chroma |
| 稀疏检索 | rank_bm25（BM25） |
| Embedding | BGE-M3（智源开源） |
| 重排序 | bge-reranker-v2-m3（Cross-encoder） |
| PDF 解析 | PyMuPDF + pdfplumber |
| 生成大模型 | DeepSeek（中科大统一 API，OpenAI 兼容） |
| 对话界面 | Gradio |
| 版本管理 | Git + GitHub |

> 详细选型说明见 [`项目主体/技术路线/技术选型方案.md`](项目主体/技术路线/技术选型方案.md)。

## 五、系统架构

系统分为两条链路：

- **离线建库链路**（一次构建）：工艺 PDF → 解析 → 分块 → 向量化 → 写入索引；
- **在线问答链路**（每次提问）：用户问题 → 查询改写 → 混合召回 → 重排序 → 大模型生成 → 带引用的加工指令。

可视化架构图见 [`项目主体/技术路线/工艺RAG系统双链路架构.html`](项目主体/技术路线/工艺RAG系统双链路架构.html)（用浏览器打开）。
