# M2 分块与双索引

2026-11-21 在 M1 已核对的 11 页上建立开发基线：传动轴论文全部 8 页，三菱 B196C 第 19 页，Haas 手册第 220、231 页。共 107 个检索条目，其中 57 个表格行、50 个正文块。原始页码按 PDF 封面起算。两路索引使用同一组内容 ID，建库入口在发布快照前检查两路 ID 集合是否一致。

## 如何复现

从仓库根目录运行。首次建库需要 M0 的硅基流动配置，会把所选页的文本提交给嵌入服务。原始 PDF 的来源见[轴类车削样本索引](轴类车削样本索引.md)。

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python parse_pdf.py data/raw_pdfs/IJCA-transmission-shaft.pdf --output output/M1/传动轴.json
.venv/bin/python parse_pdf.py data/raw_pdfs/MMC-B196C.pdf --pages 19 --output output/M1/三菱参数表.json
.venv/bin/python parse_pdf.py data/raw_pdfs/Haas-2011.pdf --pages 220 231 --output output/M1/Haas.json
.venv/bin/python ingest.py output/M1/*.json
.venv/bin/python search.py '粗车与半精车使用什么机床？'
.venv/bin/python search.py 'MC6015 FP 每转进给量' --mode bm25
.venv/bin/python eval_retrieval.py
```

建库命令的全部输入共同定义一个快照，亦支持直接输入 PDF。重复相同输入可复用当前快照；更换语料时应提供全部需要保留的文档。输出位于 output/M2，CURRENT 指向已经校验的快照。搜索返回来源、页、正文或表格位置和条目内容。稠密路使用 BGE-M3 和 Chroma 余弦距离（越小越相似）；稀疏路使用 jieba、保留完整牌号的字母数字分词和 BM25Okapi，将词项权重持久化，支持离线查询。

## 分块与引用

正文在页内按段落或句子边界切开，目标上限 500 字符，重叠 75 字符。对有标题且能识别列名的单层表头，每个数据行建立一个可检索条目，重复附上表头和表前说明；source、page、table、row 可定位到 M1 保留的整表。row 从 1 起计，包含表头。复杂多层表头与图形区域保留页内文字，数值与列的绑定仍需核对原图；当前不会据此自动展开跨页表头。
