# 车削助手使用与验收

## 启动与复现

Python 3.12。在此仓库根目录建立虚拟环境，安装 requirements.txt 中的版本，复制 .env.example 到尚不存在的 .env，并配置自己的服务凭证。用 scripts/check_api.py 检查三个服务。原始文档按《轴类车削样本索引》下载，用《M2-分块与双索引》的命令解析并建库。本地已有 CURRENT 索引时可直接启动。

```sh
.venv/bin/python demo.py
.venv/bin/python ask.py '传动轴粗车与精车分别用哪台机床？' --json
.venv/bin/python nc_job.py examples/两阶外圆.dxf examples/教学工单.json
.venv/bin/python -m unittest discover -s tests
```

演示入口监听 http://127.0.0.1:7861，默认使用 qwen3.8-chat；显式设置的 USTC_MODEL 环境变量优先。问答区支持多轮、清空和展开原文。回答中的编号对应下方的 PDF 原页及片段。第二页签导出 NC 和结构化工序卡，可用自备 DXF 替换教学轮廓。所有问答请求将查询和候选证据发送到已配置的模型服务，连接外部服务时需要网络。

## 工单约定与适用范围

教学单元采用 Haas 风格的两轴外圆车削，X 为直径、Z0 为已加工端面、负 Z 指向卡盘、G54 为工件坐标。预置 T0101 对刀且机床处于已核准的安全换刀位置。材料 S45C，HB180～280，刀片 MC6015 FP，负角外圆一般精加工。工单显式输入毛坯直径、实际伸出长度、固定转速、每转进给。软件从本地知识库检索三菱表格并校验刀具、硬度、线速度、每转进给及切深范围。三菱原件缺失或当前索引未收录适用行时需要补齐证据。

DXF 单位为毫米，模型空间仅含 TURN_PROFILE 图层的一条开放 LWPOLYLINE，横坐标为 Z、纵坐标为半径。从 Z0 开始，沿负 Z 排列直径逐级增加的直线轴段与径向轴肩。工单规定已完成端面和毛坯准备。可处理多段、不同直径和长度；输入检查会拒绝圆弧、槽、键槽、任意自由曲面和超过现有工艺依据的切深。当前演示件原生 DXF 为项目自建，车间配置为教学假设。FCStd 曲轴仅作范围边界样本。

先评估毛坯、直径范围和夹持空间，再按从长至短的外圆行程输出。程序以理想刀尖模型独立回放各段 X/Z 运动，检查轴段终态外径、径向定位及快速移动穿料。预期初始位置、工件原点、刀具补偿、刀尖圆弧、机床配置、夹具干涉及真实加工质量需要目标设备独立验证。现场审核前仅作离线编程参考。[Haas 编程手册](https://www.haascnc.com/content/dam/haascnc/en/service/manual/operator/english---lathe-ngc---operator%27s-manual---2025.pdf)

## 验收

使用 evaluate_system.py --out 指定新目录运行 24 题端到端验收。每次保留 answers.jsonl、metrics.json 和人工评分.csv。指标包含单进程常驻内存抽样、服务耗时、错误数和标注来源页覆盖。首次建库、浏览器、外部模型服务器的资源未计入问答进程。开发集的 6 题保留作回归，其余题为新增样本；同一公开语料上的测试不代表新车间。

独立评审者应展开引用、查看原页、比较工序条件和单位，然后在评分表填写事实正确性、引用支持度、姓名及错因。拒答题以是否正确识别资料缺失评分。可复制表格分别评审并复核分歧。运行 python scripts/score_reviews.py 评分表路径 汇总，未评样本保留待评。另用 eval_retrieval.py 和 eval_retrieval.py --m4 分别复现检索与重排对照。
